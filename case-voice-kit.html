The problem

The course needed narration for 22 units in the teacher's voice, without hours of studio recording or uploading his voice to a paid service.

Constraints

  • Runs on a Windows PC, free.
  • Nothing leaves the machine.
  • The speaker must agree to having their voice cloned.

How it works

  1. 1 to 2 minute recording
  2. Pick the best 10-second clip
  3. Create the voice
  4. Type text, choose tone and language
  5. Quality check
  6. .wav or .mp3

Decisions and why

Local and open source

Built on Chatterbox (MIT licence), so there's no subscription and no recording is uploaded anywhere.

Consent built in

A voice can't be created until the consent box is ticked.

Check every output

Each result is scored for how close it sounds to the voice and whether every word was actually spoken, so bad takes are caught before anyone hears them.

A short install path on Windows

PyTorch's files break Windows' 260-character path limit in deep folders, so the setup script installs to a short path.

Results

  • Used to produce the A1 and A2 course audio, with the teacher's permission.

Limits

  • Windows only. Real time with an NVIDIA GPU, several times slower on CPU.
